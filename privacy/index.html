Norme sulla privacy

Wyrd è un'applicazione per uso personale del suo autore. Non è destinata ad altri utenti.

Dati a cui accede

Con l'autorizzazione Google Calendar (https://www.googleapis.com/auth/calendar) l'applicazione legge, crea e modifica eventi nel calendario dell'autore, per pianificare la giornata.

Uso e conservazione

I dati del calendario vengono usati solo per questo scopo e restano sui server personali dell'autore. Non vengono venduti, condivisi con terzi né usati per pubblicità.

L'uso delle informazioni ricevute dalle API Google rispetta le Google API Services User Data Policy, compresi i requisiti di Limited Use.

Revoca

L'accesso si può revocare in qualsiasi momento da myaccount.google.com/permissions.
